# Firefox Orange Theme

Минималистичная оранжевая тема для Firefox: `userChrome.css` + `userContent.css`.
Панель закладок только с иконками, а название появляется во всплывающей подсказке при наведении.

## Особенности

- Оранжевая цветовая схема интерфейса вместо стандартной фиолетовой
- Компактная панель закладок: только иконки, без текста
- Подсказка с названием при наведении на закладку
- Стилизация внутренних страниц (`userContent.css`)
- Без расширений и JavaScript, только CSS

## Установка

### 1. Включите поддержку пользовательских стилей

1. Откройте `about:config`
2. Найдите параметр `toolkit.legacyUserProfileCustomizations.stylesheets`
3. Установите значение `true`

### 2. Найдите папку профиля

Откройте `about:support` и нажмите **Open Folder / Открыть папку** рядом с «Папка профиля».

Обычное расположение:

| ОС      | Путь                                                    |
|---------|---------------------------------------------------------|
| Windows | `%APPDATA%\Mozilla\Firefox\Profiles\<профиль>\`         |
| Linux   | `~/.mozilla/firefox/<профиль>/`                         |
| macOS   | `~/Library/Application Support/Firefox/Profiles/<профиль>/` |

### 3. Скопируйте файлы

Скопируйте папку `chrome` из этого репозитория в папку профиля.
Если `chrome` там уже есть, добавьте файлы в неё (сделайте резервную копию своих).

### 4. Перезапустите Firefox

Полностью закройте и откройте браузер заново.
